# 🚀 NorteProget

## 📋 Descripción

**NorteProget** es una plataforma digital fullstack desarrollada bajo metodología ágil (Scrum). El proyecto está organizado en dos módulos principales: Frontend (SPA con React) y Backend (API REST con Node.js/Express).

---

## 🏗️ Estructura General

```
NorteProget/
├── frontend/      # Aplicación React (SPA)
├── backend/       # API REST (Node.js + Express)
├── README.md      # Este archivo
└── docs/          # Documentación del proyecto (.docx)
```

---

## 🛠️ Stack Completo

### Frontend
- React 18 + Vite
- React Router DOM 6
- Tailwind CSS
- Axios
- JWT Decode

### Backend
- Node.js 18+
- Express.js
- Sequelize (ORM)
- PostgreSQL
- JWT + Bcrypt
- Middlewares (Auth, Roles, Validación)

---

## 🔀 Estrategia de Branches

| Branch | Propósito |
|--------|-----------|
| `GrupalPrincipal` | Producción - versión estable |
| `main` | Staging / Pre-producción |
| `developers` | Desarrollo activo del equipo |
| `feature/*` | Features individuales |
| `fix/*` | Corrección de bugs |

---

## 🚀 Quick Start

```bash
# Clonar
git clone https://github.com/gaby28894178/NorteProget.git
cd NorteProget

# Backend
cd backend && npm install && npm run dev

# Frontend (otra terminal)
cd frontend && npm install && npm run dev
```
